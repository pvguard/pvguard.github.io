CrawlerGhost

Herramienta desarrollada en Python para realizar crawling web, recolectar URLs internas, identificar rutas del dominio principal y separar subdominios encontrados durante el reconocimiento. Ideal para auditorías de seguridad, pentesting web y análisis inicial de superficie de exposición en entornos autorizados.

Python 3.8+ aiohttp + asyncio BeautifulSoup Modo Legacy Linux / Kali / Ubuntu

¿Qué es CrawlerGhost?

CrawlerGhost permite rastrear un sitio web objetivo y recolectar enlaces internos encontrados en diferentes etiquetas HTML. Su objetivo principal es construir una lista ordenada de rutas útiles para la fase de reconocimiento.

La herramienta ayuda a descubrir endpoints, rutas internas, formularios, recursos enlazados y posibles secciones expuestas que luego pueden ser analizadas manualmente o con otras herramientas.

Uso responsable

Esta herramienta debe utilizarse únicamente en dominios propios, laboratorios controlados o entornos donde se cuente con autorización explícita. No está diseñada para atacar sistemas de terceros ni para realizar actividades no autorizadas.

Características principales

Crawling interno

Recolecta URLs internas del dominio objetivo, normaliza enlaces y evita duplicados durante el rastreo.

Subdominios

Permite incluir URLs de subdominios encontrados desde enlaces internos usando la opción -s.

Modo legacy

Incluye un modo alternativo basado en requests, mechanicalsoup y BeautifulSoup.

  • Extracción desde etiquetas HTML como <a href="">, <link href="">, <script src="">, <iframe src=""> y <form action="">.
  • Soporte para crawling asíncrono usando aiohttp y asyncio.
  • Control de profundidad con -d o --depth.
  • Control de concurrencia con -c o --concurrency.
  • Modo verbose para visualizar cada URL analizada durante la ejecución.
  • Salida automática en archivo urls.txt o archivo personalizado.
  • Filtro de archivos estáticos como imágenes, CSS, JS, PDFs, ZIPs, videos y fuentes.
  • Ideal para reconocimiento web inicial en auditorías de seguridad autorizadas.

Ejecución de Herramienta CrawlerGhost: instalación, crawling, recolección de URLs y revisión del archivo generado.

Instalación

Clona el repositorio, asigna permisos de ejecución e instala las dependencias necesarias.

terminal · install 
┌──(kali㉿ghost)-[~]
└─$ git clone https://github.com/joepm21/crawlerghost.git

┌──(kali㉿ghost)-[~]
└─$ cd crawlerghost

┌──(kali㉿ghost)-[~/crawlerghost]
└─$ chmod +x crawlerghost

┌──(kali㉿ghost)-[~/crawlerghost]
└─$ python3 -m pip install -r requirements.txt

Requisitos

  • Python 3.8 o superior.
  • pip instalado.
  • Sistema Linux recomendado: Kali Linux, Parrot OS, Ubuntu o Debian.
  • Conexión hacia el dominio objetivo autorizado.

Dependencias principales

aiohttp beautifulsoup4 lxml requests mechanicalsoup urllib3 certifi yarl

Uso básico

Ejecuta la herramienta indicando el dominio o URL objetivo con la opción -t. Por defecto, los resultados se guardarán en urls.txt.

terminal · basic crawling 
┌──(kali㉿ghost)-[~/crawlerghost]
└─$ ./crawlerghost -t https://example.com/

Incluir subdominios

La opción -s permite guardar URLs pertenecientes a subdominios encontrados durante el crawling.

terminal · subdomains 
└─$ ./crawlerghost -t https://example.com/ -s

Modo verbose

Usa -v para visualizar en pantalla cada URL analizada durante la ejecución.

terminal · verbose mode 
└─$ ./crawlerghost -t https://example.com/ -v

Salida personalizada

Puedes cambiar el archivo donde se guardarán las URLs recolectadas usando -o.

terminal · output file 
└─$ ./crawlerghost -t https://example.com/ -o resultados.txt

Modo legacy

El modo legacy usa un comportamiento alternativo con requests, mechanicalsoup y BeautifulSoup.

terminal · legacy mode 
└─$ ./crawlerghost -t https://example.com/ --legacy

Opciones disponibles

Opción Descripción Ejemplo
-t, --target Dominio o URL objetivo. ./crawlerghost -t https://example.com/
-d, --depth Profundidad máxima del crawling. ./crawlerghost -t https://example.com/ -d 3
-c, --concurrency Número de peticiones concurrentes. ./crawlerghost -t https://example.com/ -c 5
--timeout Timeout por petición en segundos. ./crawlerghost -t https://example.com/ --timeout 10
--max-urls Cantidad máxima de URLs a visitar. ./crawlerghost -t https://example.com/ --max-urls 300
-s, --subdomains Incluye URLs de subdominios encontrados. ./crawlerghost -t https://example.com/ -s
-o, --output Archivo donde se guardan los resultados. ./crawlerghost -t https://example.com/ -o urls.txt
-v, --verbose Muestra cada URL analizada en pantalla. ./crawlerghost -t https://example.com/ -v
--legacy Usa modo compatible con requests + mechanicalsoup. ./crawlerghost -t https://example.com/ --legacy

Formato del output

CrawlerGhost separa los resultados recolectados en dos bloques: dominio principal y subdominios.

urls.txt · sample output 
[DOMINIO PRINCIPAL]
https://example.com/
https://example.com/login
https://example.com/contact
https://example.com/about

[SUBDOMINIOS]
https://blog.example.com/
https://portal.example.com/login

Nota: la opción -s incluye subdominios encontrados mediante enlaces dentro del sitio. No realiza fuerza bruta DNS ni enumeración pasiva como subfinder, assetfinder o amass.

Flujo recomendado en pentesting autorizado

Definir el objetivo

Seleccionar el dominio autorizado que será analizado durante la fase de reconocimiento.

Ejecutar crawling controlado

Usar profundidad y concurrencia moderada para obtener resultados estables sin generar carga innecesaria.

Recolectar URLs

Guardar los resultados en urls.txt o en un archivo personalizado para su posterior análisis.

Analizar rutas

Revisar rutas internas, formularios, endpoints, parámetros y secciones expuestas.

Alimentar otras herramientas

Usar las URLs recolectadas como entrada para pruebas manuales o herramientas de análisis web autorizadas.

terminal · recommended flow 
└─$ ./crawlerghost -t https://example.com/ -s -d 3 -c 3 -o urls.txt

└─$ cat urls.txt

¿Por qué pueden variar los resultados?

  • Redirecciones del servidor.
  • Timeouts o respuestas lentas.
  • Contenido dinámico.
  • CDN o balanceadores.
  • Cookies o sesiones.
  • Enlaces cargados condicionalmente.

Recomendación operativa

Para obtener resultados más estables, reduce la concurrencia y limita la profundidad inicial. Luego puedes incrementar gradualmente los valores según el comportamiento del sitio.

terminal · stable mode 
└─$ ./crawlerghost -t https://example.com/ -c 3 -d 2
