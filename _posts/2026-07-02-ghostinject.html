GhostInject: Interfaz gráfica profesional para pruebas controladas de SQL Injection con sqlmap

GhostInject es una herramienta gráfica orientada a Linux que facilita el flujo de trabajo de un pentester durante pruebas autorizadas de SQL Injection. Permite configurar objetivos, cookies, headers, proxy, tamper scripts, nivel de prueba, riesgo, técnicas de inyección y acciones rápidas desde una interfaz visual basada en una consola en vivo.

🐧 Linux x86_64 ⚡ Powered by sqlmap 🧩 Burp Request Support 🛡️ Pentesting Autorizado
Ver repositorio en GitHub Instalación rápida
⚠️ Uso responsable: esta herramienta debe utilizarse únicamente en laboratorios, CTFs, entornos propios o sistemas donde exista autorización explícita para realizar pruebas de seguridad.

👻 ¿Qué es GhostInject?

GhostInject nace como una utilidad para centralizar y agilizar tareas comunes de validación SQLi usando sqlmap, pero con una interfaz gráfica más ordenada para el trabajo diario de un pentester.

En lugar de construir manualmente cada comando desde terminal, la herramienta permite configurar parámetros esenciales desde la GUI, visualizar el comando generado antes de ejecutarlo y revisar la salida en una consola integrada.

1

Objetivos controlados

Permite trabajar con una URL directa o con un request HTTP exportado desde Burp Suite.

2

Configuración avanzada

Soporta cookies, headers, User-Agent, proxy, DBMS, técnicas, level, risk y threads.

3

Evidencia técnica

Incluye consola en vivo, preview del comando y opción para guardar la salida en archivo de evidencia.

✨ Características principales

⚙️

GUI tipo pentester

Interfaz gráfica basada en PyQt5 con estilo profesional para pruebas técnicas.

🧪

Motor sqlmap

Utiliza sqlmap como motor principal para pruebas controladas de SQL Injection.

📄

Request de Burp

Permite cargar archivos de request HTTP para trabajar con cookies, tokens y peticiones completas.

🌐

Proxy HTTP/S

Compatible con proxies como Burp Suite o OWASP ZAP para revisar el tráfico generado.

🧬

Tamper scripts

Soporta tamper scripts para escenarios donde se requiera ajustar payloads de prueba.

💾

Guardar salida

Permite exportar la salida como evidencia técnica para documentación o reportes.

🚀 Instalación rápida

GhostInject se distribuye como binario para Linux. El requisito principal es contar con sqlmap instalado y disponible en el PATH.

terminal · instalación 
# Instalar sqlmap
ghost@kali:~$ sudo apt update
ghost@kali:~$ sudo apt install -y sqlmap

# Clonar el repositorio
ghost@kali:~$ git clone https://github.com/joepm21/GhostInject.git
ghost@kali:~$ cd GhostInject

# Dar permisos de ejecución
ghost@kali:~/GhostInject$ chmod +x GhostInject

# Ejecutar la herramienta
ghost@kali:~/GhostInject$ ./GhostInject

Instalación opcional como comando global

terminal · comando global 
ghost@kali:~/GhostInject$ sudo cp GhostInject /usr/local/bin/ghostinject
ghost@kali:~/GhostInject$ sudo chmod +x /usr/local/bin/ghostinject

# Luego podrás ejecutarlo desde cualquier ruta
ghost@kali:~$ ghostinject

🧭 Flujo de uso recomendado

Ejecuta GhostInject desde un entorno gráfico Linux como Kali, Debian, Ubuntu o derivados.
Confirma que el objetivo forma parte de un laboratorio, CTF, auditoría autorizada o entorno propio.
Ingresa una URL objetivo o carga un archivo de request HTTP exportado desde Burp Suite.
Configura cookies, headers, User-Agent, proxy, parámetro vulnerable, DBMS, nivel, riesgo, threads y técnica.
Usa Preview Command para revisar el comando antes de ejecutarlo.
Ejecuta una acción rápida como Test Injection, Enumerate DBs, DB Banner, Tables, Columns o Dump Table.
Guarda la salida como evidencia técnica usando la opción Save Output.

⚙️ Opciones soportadas

GhostInject construye comandos de sqlmap utilizando las opciones seleccionadas desde la interfaz.

sqlmap · opciones integradas 
-u <URL>
-r <REQUEST_FILE>
-p <PARAMETER>
--cookie <COOKIE>
--user-agent <USER_AGENT>
--headers <HEADERS>
--level <1-5>
--risk <1-3>
--threads <N>
--dbms <DBMS>
--technique <B|E|U|S|T|Q>
--batch
--random-agent
--forms
--crawl=2
--fresh-queries
--proxy <PROXY>
--tamper <TAMPER_SCRIPT>
--output-dir <DIRECTORY>

También incluye un campo para argumentos extra en casos avanzados, por ejemplo:

extra args 
--delay=1 --timeout=20 --retries=2

⚡ Acciones rápidas disponibles

Acción Descripción técnica
Test Injection Ejecuta una prueba base contra el objetivo configurado.
Enumerate DBs Enumera bases de datos disponibles usando la opción --dbs.
DB Banner Obtiene el banner del motor de base de datos mediante --banner.
Tables Enumera tablas de una base de datos específica.
Columns Enumera columnas de una tabla específica.
Dump Table Extrae información de una tabla dentro de un entorno autorizado.
Preview Command Muestra el comando completo antes de ejecutarlo.
Save Output Guarda la salida de consola como evidencia.
Clear All Limpia campos, consola, preview y notas.
Stop Detiene el proceso de sqlmap en ejecución.

🧩 Uso con request de Burp Suite

Una de las funciones más útiles de GhostInject es la posibilidad de trabajar con un request HTTP capturado desde Burp Suite. Esto ayuda cuando la prueba requiere cookies, tokens, headers personalizados o una petición POST completa.

flujo · Burp Suite 
Burp Suite → Intercept → Send to Repeater → Save item/request → cargar en GhostInject

🛠️ Solución de problemas comunes

sqlmap was not found

Instala sqlmap y valida que esté disponible en el sistema:

fix · sqlmap 
sudo apt install -y sqlmap
which sqlmap
sqlmap --version

Permission denied

Otorga permisos de ejecución al binario:

fix · permisos 
chmod +x GhostInject

Error gráfico o Qt

Ejecuta la herramienta desde un entorno de escritorio Linux. Si usas SSH, habilita forwarding gráfico:

fix · entorno gráfico 
ssh -X usuario@host
./GhostInject
