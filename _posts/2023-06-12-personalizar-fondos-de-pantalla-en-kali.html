Personalizar Fondos de Pantalla en Kali Linux XFCE

Personaliza la apariencia de Kali Linux XFCE

Guía práctica para modificar el fondo de pantalla del inicio de sesión en Kali Linux XFCE, personalizar la imagen del usuario y utilizar una herramienta gráfica para automatizar el proceso.

🐉 Kali Linux 🖥 XFCE 🎨 Customization ⌨ Terminal ⚙ Linux
Los nombres y rutas de archivos relacionados con el inicio de sesión pueden variar entre versiones de Kali Linux y configuraciones del entorno gráfico. Esta guía documenta el procedimiento utilizado en el entorno mostrado en las capturas.

📘 Introducción

Kali Linux puede personalizarse de muchas formas, desde el escritorio y los iconos hasta la apariencia de la pantalla de inicio de sesión.

En esta guía veremos cómo sustituir manualmente la imagen utilizada como fondo durante el login, cómo personalizar el icono asociado al usuario y qué podemos hacer cuando una imagen no aparece correctamente.

Finalmente veremos una alternativa más cómoda: una herramienta que desarrollé para automatizar buena parte de este procedimiento.

🖼 Preparar el nuevo fondo

El primer paso consiste en descargar o crear la imagen que queremos utilizar como fondo.

Para obtener un resultado visual adecuado conviene utilizar una resolución cercana a la de nuestro monitor y mantener una relación de aspecto compatible con la pantalla.

🖼

Imagen

Selecciona un wallpaper con suficiente resolución para evitar pérdida de calidad.

📐

Resolución

Utiliza preferentemente una imagen adaptada al tamaño y proporción de tu monitor.

💾

Respaldo

Antes de reemplazar archivos del sistema conserva una copia del fondo original.

💾 01. Respaldar el fondo original

Antes de modificar el archivo utilizado por el sistema es recomendable conservar una copia de respaldo.

En el procedimiento original se renombra el archivo background como backgroundcopy.

kali@linux · backup-background 
┌──(kali㉿kali)-[~]
└─$ sudo mv /usr/share/desktop-base/kali-theme/login/background /usr/share/desktop-base/kali-theme/login/backgroundcopy
Respaldo del archivo utilizado como fondo de inicio de sesión
Importante: verifica siempre que la ruta exista en tu instalación antes de ejecutar el comando. Mantener el archivo original facilita revertir la personalización si fuera necesario.

🎨 02. Copiar el nuevo fondo

Después de guardar el fondo original podemos copiar nuestra nueva imagen hacia la ruta utilizada por el tema de inicio de sesión:

/usr/share/desktop-base/kali-theme/login/background
Ruta utilizada para almacenar el fondo del inicio de sesión

Copiar la imagen

kali@linux · copy-background 
┌──(kali㉿kali)-[~]
└─$ sudo cp "Image_PATH _DIRECTORY" /usr/share/desktop-base/kali-theme/login/background
Sustituye "Image_PATH _DIRECTORY" por la ruta correspondiente a la imagen que deseas utilizar.

Después de copiar la nueva imagen, el sistema debería utilizarla como fondo en la pantalla de inicio de sesión de acuerdo con la configuración documentada.

Resultado del fondo personalizado en la pantalla de inicio de sesión

👤 03. Personalizar el icono del usuario

Además del fondo de pantalla, también podemos personalizar la imagen asociada al usuario que aparece durante el inicio de sesión.

El procedimiento mostrado en esta guía se realiza desde las opciones gráficas del sistema, seleccionando una nueva imagen para el usuario.

Acceso a las opciones de configuración del usuario
Selección de una nueva imagen para el perfil del usuario
Configuración del nuevo icono del usuario

🛠 04. Solución de problemas con la imagen

En algunos casos puede aparecer un error al intentar seleccionar la imagen o esta puede no mostrarse correctamente.

En el escenario documentado, una solución consiste en colocar temporalmente la imagen dentro de una ubicación accesible desde el usuario root y posteriormente seleccionarla desde las opciones mostradas anteriormente.

Ubicación utilizada para trabajar con la imagen desde root
Selección del archivo utilizado para personalizar el usuario
Atención: evita modificar permisos o propietarios de archivos del sistema de manera indiscriminada. Si la imagen no aparece, verifica primero la ruta, el formato, los permisos de lectura y la configuración de tu versión de Kali Linux.

⚡ 05. Automatizar el proceso

Aunque el procedimiento manual resulta útil para comprender dónde se encuentran los archivos utilizados por el sistema, realizar estas modificaciones varias veces puede resultar poco práctico.

Por ese motivo desarrollé una herramienta para simplificar el proceso de personalización del fondo de inicio de sesión en Kali Linux.

Change Login Background

Herramienta desarrollada para facilitar la selección y aplicación de fondos personalizados en el entorno de inicio de sesión.

Descarga la versión correspondiente desde la sección Releases.
Proporciona permisos de ejecución cuando corresponda.
Ejecuta la aplicación y selecciona la imagen que deseas utilizar.
Aplica el fondo y verifica el resultado en la pantalla de inicio de sesión.

📋 Resumen del procedimiento

Preparar una imagen adaptada a la resolución de la pantalla.
Crear una copia del fondo original utilizado por Kali Linux.
Copiar la nueva imagen hacia la ubicación utilizada por el tema de login.
Verificar el resultado desde la pantalla de inicio de sesión.
Personalizar también la imagen asociada al usuario si se desea.
Utilizar Change Login Background si prefieres automatizar el proceso.

🏁 Conclusión

Kali Linux ofrece múltiples posibilidades de personalización y el fondo del inicio de sesión es solo una de ellas.

Realizar inicialmente el procedimiento de forma manual ayuda a comprender qué archivos participan en la configuración del entorno gráfico y por qué es recomendable conservar siempre una copia de respaldo.

Cuando necesitamos realizar el proceso con mayor frecuencia, una herramienta gráfica puede simplificar significativamente la tarea y reducir la cantidad de modificaciones manuales necesarias.
