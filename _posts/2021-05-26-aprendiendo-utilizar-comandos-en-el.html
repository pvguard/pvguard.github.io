🐧 GNU/LINUX · TERMINAL · CYBERSECURITY

Fundamentos de GNU/Linux

Historia, arquitectura y comandos esenciales para comenzar a dominar uno de los sistemas más importantes dentro de la administración de infraestructura, servidores y ciberseguridad.

🐧 GNU/Linux 🐉 Kali Linux ⌨ Terminal 🌐 Networking 🛡 Cybersecurity
Esta guía está orientada a comprender los fundamentos de GNU/Linux y adquirir una base sólida para trabajar posteriormente con sistemas, redes y herramientas de ciberseguridad.

📘 Introducción

GNU/Linux constituye una de las plataformas más importantes dentro de la administración de sistemas, infraestructura, desarrollo y, especialmente, la ciberseguridad.

Su flexibilidad, estabilidad y amplio ecosistema de herramientas hacen que comprender su funcionamiento sea una habilidad fundamental para cualquier profesional relacionado con tecnologías de información y seguridad informática.

Aprender GNU/Linux puede parecer complejo al principio. La terminal, la estructura del sistema de archivos, los permisos y la gran cantidad de comandos disponibles pueden resultar poco familiares para quienes provienen de otros sistemas operativos.

Sin embargo, con práctica constante estos conceptos comienzan a formar parte natural del trabajo diario.

Después de varios años utilizando sistemas GNU/Linux, una de las lecciones más importantes que he aprendido es que siempre existe algo nuevo por descubrir.

Esto resulta especialmente evidente dentro de la ciberseguridad, donde aparecen constantemente nuevas tecnologías, técnicas, herramientas y metodologías.

💡 Consejo: no intentes memorizar todos los comandos de Linux. Aprende primero qué hacen, comprende su funcionamiento, consulta la documentación y utilízalos constantemente dentro de laboratorios controlados.

En esta guía veremos desde los orígenes de GNU/Linux hasta algunos de los comandos fundamentales que todo usuario debería conocer, utilizando principalmente Kali Linux como entorno para nuestros ejemplos.

📜 01. Historia de GNU/Linux

Para comprender GNU/Linux debemos remontarnos a UNIX, un sistema operativo desarrollado originalmente a finales de la década de 1960 en los laboratorios Bell.

UNIX introdujo numerosos conceptos que posteriormente influirían profundamente en el diseño de otros sistemas operativos.

Años después, en 1983, Richard Stallman anunció el Proyecto GNU, cuyo objetivo era desarrollar un sistema operativo compatible con Unix compuesto completamente por software libre.

🦬 02. ¿Qué es GNU?

GNU significa:

GNU = GNU's Not Unix

Es un acrónimo recursivo utilizado para identificar el proyecto iniciado por Richard Stallman.

El Proyecto GNU desarrolló numerosos componentes esenciales para un sistema operativo, incluyendo compiladores, bibliotecas, shells, herramientas de línea de comandos y diferentes utilidades.

Sin embargo, todavía faltaba una pieza fundamental para completar el sistema: un kernel plenamente funcional.

🐧 03. ¿Qué es Linux?

En 1991, Linus Torvalds comenzó el desarrollo de Linux.

Uno de los conceptos que debemos comprender es que Linux técnicamente hace referencia al kernel y no necesariamente a todo el sistema operativo que utilizamos habitualmente.

Al combinar el kernel Linux con diferentes herramientas y componentes del ecosistema GNU obtenemos lo que normalmente denominamos:

GNU + Linux = GNU/Linux

⚙ 04. ¿Qué es un Kernel?

El kernel o núcleo es uno de los componentes centrales de un sistema operativo.

Su función principal consiste en actuar como intermediario entre el software y los recursos físicos disponibles en el equipo.

Entre sus principales responsabilidades encontramos:

  • Administración de memoria.
  • Gestión de procesos.
  • Comunicación con dispositivos.
  • Control de recursos del sistema.
  • Gestión de sistemas de archivos.
  • Interacción entre software y hardware.
🔎 Concepto simplificado

Aplicaciones → Sistema Operativo → Kernel → Hardware

🕊 05. Las cuatro libertades del Software Libre

El concepto de Software Libre se fundamenta tradicionalmente en cuatro libertades esenciales.

Libertad Descripción
Libertad 0 Ejecutar el programa para cualquier propósito.
Libertad 1 Estudiar cómo funciona el programa y modificarlo según las necesidades del usuario.
Libertad 2 Redistribuir copias del programa.
Libertad 3 Distribuir versiones modificadas para que otras personas puedan beneficiarse de las mejoras.
💡 Importante

El acceso al código fuente es necesario para poder estudiar y modificar un programa de acuerdo con los principios del Software Libre.

📦 06. Distribuciones GNU/Linux

Actualmente existen numerosas distribuciones GNU/Linux diseñadas para diferentes tipos de usuarios y necesidades.

Debian Ubuntu Fedora Arch Linux Linux Mint Kali Linux

Una distribución normalmente integra el kernel Linux junto con herramientas, gestores de paquetes, interfaces gráficas, bibliotecas y aplicaciones.

  • Pentesting.
  • Análisis de redes.
  • Auditoría de aplicaciones.
  • Análisis forense.

💻 08. Introducción a la terminal

La terminal constituye una de las herramientas más importantes dentro de GNU/Linux.

Mediante ella podemos administrar archivos, procesos, usuarios, servicios, interfaces de red y prácticamente cualquier componente del sistema operativo.

💡 Recuerda

No necesitas memorizar todas las opciones de un comando. Linux incorpora documentación que podemos consultar directamente desde la terminal.

Consultar el manual de un comando

kali@linux · manual 
┌──(kali㉿kali)-[~]
└─$ man ls

También podemos consultar rápidamente las opciones disponibles:

kali@linux · help 
┌──(kali㉿kali)-[~]
└─$ ls --help

📂 09. Navegación por directorios

pwd

Muestra la ruta absoluta del directorio donde nos encontramos actualmente.

kali@linux · pwd 
pwd

/home/kali

ls

Permite listar archivos y directorios.

kali@linux · ls 
ls

Mostrar información detallada:

kali@linux · ls 
ls -l

Mostrar también archivos ocultos:

kali@linux · ls 
ls -la

cd

Permite desplazarnos entre directorios.

kali@linux · cd 
cd directorio

Regresar al directorio superior:

kali@linux · cd 
cd ..

Volver al directorio anterior:

kali@linux · cd 
cd -

Ir al directorio personal:

kali@linux · home 
cd ~

Ir directamente a la raíz:

kali@linux · root 
cd /

📁 10. Gestión de archivos y directorios

Crear un directorio

kali@linux · mkdir 
mkdir laboratorio

Crear un archivo vacío

kali@linux · touch 
touch notas.txt

Visualizar un archivo

kali@linux · cat 
cat notas.txt

Copiar archivos

kali@linux · cp 
cp archivo.txt copia.txt

Mover un archivo

kali@linux · mv 
mv archivo.txt /home/kali/Documentos/

Renombrar un archivo

kali@linux · mv 
mv archivo.txt nuevo_nombre.txt

Eliminar un archivo

kali@linux · rm 
rm archivo.txt

Eliminar un directorio vacío

kali@linux · rmdir 
rmdir directorio

Eliminar recursivamente un directorio

kali@linux · rm 
rm -r directorio
⚠ Precaución

El comando rm elimina información directamente. Antes de utilizar opciones recursivas o forzadas verifica siempre que la ruta especificada sea correcta.

👤 11. Usuarios y privilegios

Consultar el usuario actual

kali@linux · identity 
whoami

Ejecutar comandos con privilegios administrativos

kali@linux · sudo 
sudo <comando>

Ejemplo:

kali@linux · apt 
sudo apt update

Abrir una shell como root

kali@linux · root shell 
sudo -i
🔐 Principio de mínimo privilegio

No es necesario trabajar permanentemente como root. Para tareas administrativas específicas puede utilizarse sudo.

🔐 12. Permisos en Linux

GNU/Linux utiliza permisos para determinar qué usuarios pueden leer, modificar o ejecutar determinados archivos.

Los principales permisos son:

Permiso Significado
r Read / Lectura
w Write / Escritura
x Execute / Ejecución

Visualizar permisos

kali@linux · permissions 
ls -la

Modificar permisos

kali@linux · chmod 
chmod +x script.sh

El ejemplo anterior añade permiso de ejecución al archivo script.sh.

⚙ 13. Procesos del sistema

Mostrar procesos en tiempo real

kali@linux · process monitor 
top

Listar procesos

kali@linux · ps 
ps aux

Mostrar trabajos de la shell

kali@linux · jobs 
jobs

Finalizar un proceso

kali@linux · kill 
kill <PID>

Donde PID corresponde al identificador del proceso.

🌐 14. Redes y conectividad

Mostrar interfaces de red

kali@linux · network interfaces 
ip addr

También puede utilizarse:

kali@linux · network interfaces 
ip a

Mostrar tabla de rutas

kali@linux · routing 
ip route

Consultar interfaces

kali@linux · links 
ip link

Comprobar conectividad

kali@linux · connectivity 
ping 8.8.8.8

También podemos verificar conectividad utilizando un nombre DNS:

kali@linux · dns connectivity 
ping google.com

Consultar el hostname

kali@linux · hostname 
hostname

Consultar información del sistema

kali@linux · system info 
uname -a

Buscar contenido con grep

grep permite buscar patrones o cadenas dentro de archivos.

kali@linux · grep 
grep "root" /etc/passwd

Buscar archivos con find

kali@linux · find 
find /home/kali -name "*.txt"

Descargar archivos con wget

kali@linux · wget 
wget https://example.com/archivo.zip

Consultar espacio disponible

kali@linux · disk 
df -h

La opción -h muestra los valores utilizando unidades más fáciles de interpretar.

Consultar historial

kali@linux · history 
history

Limpiar la terminal

kali@linux · clear 
clear

🔧 15. Gestión de servicios

En distribuciones modernas que utilizan systemd podemos administrar servicios mediante el comando systemctl.

Consultar Apache

kali@linux · apache2 
sudo systemctl status apache2

Iniciar Apache

kali@linux · apache2 
sudo systemctl start apache2

Detener Apache

kali@linux · apache2 
sudo systemctl stop apache2

Reiniciar Apache

kali@linux · apache2 
sudo systemctl restart apache2

Consultar nuevamente su estado

kali@linux · apache2 
sudo systemctl status apache2

PostgreSQL

kali@linux · postgresql 
sudo systemctl start postgresql

🔄 16. Actualizar Kali Linux

Mantener nuestro sistema operativo actualizado permite disponer de nuevas versiones de herramientas, correcciones de errores y actualizaciones de seguridad.

⚠ Importante

Los siguientes comandos requieren privilegios administrativos. Utilizaremos sudo cuando sea necesario.

Actualizar repositorios

kali@linux · update 
sudo apt update

Actualizar paquetes

kali@linux · upgrade 
sudo apt full-upgrade -y

Eliminar dependencias innecesarias

kali@linux · cleanup 
sudo apt autoremove

kali@linux · help

🏁 18. Conclusiones

Aprender GNU/Linux no consiste únicamente en memorizar comandos.

Lo realmente importante es comprender cómo está organizado el sistema, cómo interactúan sus componentes y cómo podemos utilizar la terminal para administrar nuestro entorno de manera eficiente.

Para quienes nos desenvolvemos dentro del área de ciberseguridad, estos conocimientos constituyen una base fundamental.

Muchas herramientas, servidores, laboratorios, servicios cloud y plataformas utilizadas diariamente dentro de seguridad informática funcionan sobre tecnologías Linux.

Por este motivo, comprender el sistema y dominar progresivamente la terminal facilitará considerablemente el aprendizaje de conceptos más avanzados.

💡 Mi recomendación

Practica constantemente. Crea máquinas virtuales, monta laboratorios, consulta la documentación, analiza cada comando y experimenta en entornos controlados.

Con el tiempo, trabajar desde una terminal dejará de parecer complicado y se convertirá en una herramienta natural dentro de tu flujo de trabajo.

“La práctica constante transforma los comandos en conocimiento y el conocimiento en experiencia.”
