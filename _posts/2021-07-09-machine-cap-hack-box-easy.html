Hola mis estimados lectores en esta oportunidad voy a mostrarles la solución para esta maquina de HTB. 
Una excelente caja para los que recién se están iniciando en el mundo del hacking mas que todo para practicar y desarrollar nuevos conocimientos en esta rama de la seguridad informática.
Sin mas que decir comenzamos.

Bueno como en todas las cajas anteriores vamos a proceder a analizar la dirección ip de la maquina para ver que podemos encontrar en este caso es 10.10.10.245


Como vemos hay 3 puertos abiertos: 
  • 21:ftp
  • 22:ssh
  • 80:http
Probamos el puerto 21:ftp y vemos que nos pide un password. probamos con anonymous contraseña por defecto ftp pero nos arroja failed.

Bueno pasamos con el puerto 80 aver a que nos dirige 


No es mas que una simple pagina, pero veremos que esconde. hay algo que nos puede interesar :)

Vamos a ejecutar Gobuster para enumar los directorios y ver que esconde esta pagina.


Probamos con cada uno de los directorios que nos muestra.
Me llamo la atención el directorio /data
pero en gobuster no arroja mas que ese directorio para ello utilizare dirb para que me enumere lo que hay dentro de /data


Vemos que nos arroja varios archivos dentro de data, vamos a probar con cada uno de ellos aver que contiene.



Vamos a decargar ese archivo para observar que contiene 0.cap




Buscando en este documento veo que hay una cantidad de solicitudes FTP, me percate que hay un usuario y una contraseña. 

Vamos a proceder a ponerlo en el ssh para ver si hay una conexión


Nos da una conexión con el usuario y capturamos la bandera de usuario.



Bueno ahora procederé a escalar privilegio para ello voy a ejecutar linpeas.sh , que tuve que subirlo desde mi maquina.


Después de analizar la salida de linpeas, encontré una pestana de capacidades que tiene python 3.8 que nos permitirá ingresar al modo root 

https://gtfobins.github.io/gtfobins/python/

Te comparto esta nota que me sirvió mucho para escalar privilegio de esta maquina

# python3 -c 'import os; os.setuid(0); os.system("/bin/sh")'
