Revisemos el contenido del archivo dentro /usr/local/bin/enableSSH.sh
La addkey() función parece interesante. 


Lo que hace este script es escribir una clave id_rsa.pub definida en clave en un archivo de formato generado aleatoriamente /tmp/ssh-XXXXXXXXy luego copia el contenido del archivo en known_hosts la raíz. Y luego borra el archivo tmp. 
Entonces, si podemos escribir nuestra propia clave ssh en el archivo tmp antes de que se copie en known_hosts, nuestra clave se escribirá en known_hosts y podremos ssh en root. Así que escribimos un bucle while infinito en bash que escribe continuamente nuestra clave ssh en cualquier archivo de formato /tmp/ssh-XXXXXXXXusando caracteres comodín. Y mientras esto se ejecuta, ejecutamos el script como sudo varias veces, ya que no podemos estar seguros, si la clave se escribió antes de que se eliminara el archivo.

Creamos la id_rsa
Primero ejecutaremos el while luego ejecutamos el sudo 3 o 4 veces.

while true; do echo "id_rsa.pub" | tee /tmp/ssh* > /dev/null; done

sudo /usr/local/bin/enableSSH.sh
